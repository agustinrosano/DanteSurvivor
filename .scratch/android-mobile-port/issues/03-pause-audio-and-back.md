# 03: Leave and return to a run safely

**What to build:** backgrounding pauses the game and audio, returning awaits the player's resume action, and Android Back pauses or navigates safely.

**Blocked by:** 01: Install and launch the game offline.

**Status:** ready-for-agent

- [ ] Backgrounding stops active input and pauses gameplay/audio.
- [ ] Returning does not advance simulation by the elapsed background time.
- [ ] Resume works and honors the player's sound preference.
- [ ] Back pauses a run or returns from a menu without bypassing upgrade/end-game modals.
